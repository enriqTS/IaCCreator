# AppSync → DynamoDB

The `resolves_with` connection attaches a GraphQL field to a generated DynamoDB data source and AppSync JavaScript unit resolver. Select `field_name` and one operation: `get_item`, `put_item`, `update_item`, or `delete_item`. The GraphQL `type_name` defaults to `Query` for GetItem and `Mutation` for writes. The AppSync node must contain a GraphQL schema with the selected type and field. AppSync validates the full schema and field binding during deployment.

The resolver maps GraphQL arguments to the table's configured partition key and optional sort key. By default, each key uses an argument with the same name as its table attribute; `hash_argument` and `range_argument` override those names. GetItem can request a consistent read. PutItem takes non-key item attributes from the `input` argument by default and prevents replacement of an existing item unless `overwrite` is enabled. UpdateItem replaces one non-key `update_attribute` using the `value` argument by default and requires the item to exist. DeleteItem removes the selected key. `item_argument` and `value_argument` can rename the respective GraphQL arguments. The schema must define arguments with compatible values and a return type matching the DynamoDB result.

Each connected table gets one AppSync-owned data source and role, even when several GraphQL fields use it. The role trusts `appsync.amazonaws.com` only for the generated API ARN. Its policy grants only the selected DynamoDB operations on the generated table ARN. Managed or external customer-managed table keys add key-scoped KMS permissions; external key policies must also allow the role. A table with an external key configured but encryption disabled is rejected. Cross-module values arrive through module inputs, and the data source waits for its IAM policy. A GraphQL field can have only one generated resolver, including across Lambda and DynamoDB connections.

The generated code follows the [AWS AppSync DynamoDB JavaScript helpers](https://docs.aws.amazon.com/appsync/latest/devguide/built-in-modules-js.html), and the Terraform resources follow the [AppSync data-source](https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/appsync_datasource) and [resolver](https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/appsync_resolver) references.
