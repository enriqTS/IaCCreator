# Step Functions to DynamoDB items

Connect a Step Functions workflow to a generated DynamoDB table with `accesses_item`. Select an existing top-level JSONPath Pass state through `state_name` (default `Pass`), then choose GetItem, PutItem, UpdateItem, or DeleteItem. The connection replaces the Pass state with the optimized DynamoDB Task, preserving transitions and data paths while removing placeholder Result values. The operation response becomes the state's result unless `ResultPath` discards or redirects it.

The Task uses the generated table name, and its IAM policy grants only the selected operation on the selected table ARN. The workflow's external execution role must trust `states.amazonaws.com`. If the table uses a connected or external KMS key, the role also receives a key-scoped decrypt grant. The KMS key policy must authorize DynamoDB to use the key on the role's behalf.

Runtime `key_path` (default `$.key`) and `item_path` (default `$.item`) must resolve to DynamoDB's low-level AttributeValue maps, not ordinary JSON values. GetItem, UpdateItem, and DeleteItem use `key_path`; PutItem uses `item_path`, which must include all primary-key attributes. UpdateItem requires `update_expression`. Write operations may use `condition_expression`; `expression_attribute_names_path` and `expression_attribute_values_path` supply maps for `#name` and `:value` placeholders. GetItem optionally uses a strongly consistent read. The backend validates operation-specific fields and simple JSONPath reference syntax before generating Terraform, but the execution input must supply paths and values that match the table schema. PutItem replaces an existing item unless a condition prevents it.

DynamoDB tasks compose with Secrets Manager, Lambda, ECS, Batch, SNS, and SQS tasks on distinct placeholders; overlapping bindings are rejected. Terraform preconditions recheck placeholders when the workflow definition is overridden by environment variables. Configure retries, error handling, and any conditional-write behavior for the workload.

AWS documents the [optimized Step Functions DynamoDB operations](https://docs.aws.amazon.com/step-functions/latest/dg/connect-ddb.html), [Task parameter paths](https://docs.aws.amazon.com/step-functions/latest/dg/connect-parameters.html), [PutItem replacement behavior](https://docs.aws.amazon.com/amazondynamodb/latest/APIReference/API_PutItem.html), and [DynamoDB KMS authorization](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/encryption.usagenotes.html).
